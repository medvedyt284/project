# Book database
Программа представляет собой реализованный алгоритм для анализа базы данных с книгами и поиска необходимой информации. Пользователь сможет просматривать список книг, искать по названию, году или же автору. 

# Функционал

Возможности программы:
1. Добавление книг в базу данных 
2. Поиск книг в базе данных 

Пользовательский интерфейс приложения состоит из следующих компонентов:
1. Главное меню
2. Поле поиска книг
3. Кнопка добавления книг
4. Таблица с книгами
